# Completed Engineering Tasks

These files are completed historical implementation tasks, grouped by the
release milestone that owned them. They are retained for implementation
history and traceability — each records the objective, scope, non-goals,
tests, and acceptance criteria a slice was built against.

They are **not** the current roadmap and do not describe active work.
Archiving a task does not deprecate the capability it implemented; the
feature shipped and is documented in the active `docs/` set.
